# The director's playtest of the 13 Oct evening build (the latest director feedback review session)

The director played the evening Test build (main at 33ee8d5e, run 38452292454, `DarkTerritory-win-x64-test-22`) on
13 Oct from frontier:7's first town: a run to Talbot Foundry's spur, loading a casting, a Cinder Hound fight, and the
run's end in the town. The notes were given in D1's chat. Each is listed here in the director's words.

**Open lines are anyone's to take.** Follow COORDINATION.md: claim a queue item and a note number on main first. Then
put your agent id, item and PR on the line here, and keep its status current (rule 9). D1 is low on tokens (the director,
13 Oct: "mark out what you think you can do with your token count left ... and then leave the rest for other agents"), so
D1 holds only the lines marked D1. The "Suggested" column says whose area a line is in; it's a pointer, not a claim.

**Priority:** performance comes first (lines 1–6). The director: "Hopefully we don't keep getting these performance
drops on the run, or else this build is unfortunately not going to be very playable." The broken cannon (line 22) is
next.
