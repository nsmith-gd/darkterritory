**The Tweaker.** Each creature's `game` is its `want`, and its `measured` is these nights; the measure request is done.
The page's estimate keeps the 12 Oct calibration (`model/calibration`, nights with every kind about but the Knotter):
those rates are what each kind does when it's about, and the page applies the roster's chances to them. Calibrated from
these nights, it would count every kind's absent nights twice. So to recalibrate under a roster, measure the base rates
with every kind about (`calibrate.py --uncapped` nights from a build with `nightChance` cleared) and keep these nights
for `measured`.
