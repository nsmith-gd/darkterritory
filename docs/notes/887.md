     grace and never relieved, no draw to wait for, every kind about tonight, the night's curve as the game has it) and asserts

     enemy id the tick it appeared), so a guard holds whatever the overhaul does to the log (#600's `EncounterLog`, #603's
     commit point). Each has a contrast (the same director outside the protection sends), so no guard passes by the
     director sending nothing.
