197. **A swing at nothing is seen too (note 146's "not yet"; audit order P1).** T121's HitConfirm gave a crewmate's blow a reader when it landed: every client plays their swing clip round it (`SceneArt.Crewmate`'s `swung`). A swing that hit nothing was never on the wire, since the host decides blows from intent (App. C.2), so to everyone else the crewmate stood still while they swung at a Dragger's limb that had gone, or at the dark.
    - **The host logs every swing.** `World.Swing` adds a `SwingEvent` (its id, the tick it started, who) each time a swing starts, landed or not, so one per melee recovery (`enemies.json melee.swingSeconds`) while Swing is held. They're kept as long as hits are (`combat.json hits.keepSeconds`), so a dropped snapshot doesn't lose one, and replicated as `RecordKind.Swing` (tick, who). Clients mirror them with the hits (`World.MirrorHits`).
    - **Drawn as a landed blow is.** The blow is decided on the tick the swing starts, so a landed swing's HitConfirm and its SwingEvent share a tick, and either times the clip alike. `GreyboxScene.Swung` takes the newest of the two.
    - **Prediction is untouched.** The event is host state on the world record, not the player's; the swinger's own first-person swing still plays from their own input (note 146).
