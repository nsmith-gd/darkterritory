555. **An invite accepted while playing joins in-process (N2, queue #272; the netcode audit's gap 4, note 530; note 24's relaunch).** Accepting a friend's invite (or "Join Game" on them) mid-night ended the game and started the process again with `+connect_lobby`, paying the renderer's startup and losing the menus. Now the night ends as it did (disposed, its lobby left), and the friend's lobby is simply the next launch (`Launch.JoinLobby`), through the same loading screen a JOIN from the menu goes through; Steam stays up, since the invite was its. The fresh start stays for an invite accepted from outside the game. Not testable headless (it's the app's outer loop); the console says "crew: n aboard" as the count changes, which the two-machine test (note 556) reads.
