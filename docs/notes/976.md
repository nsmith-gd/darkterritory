Budget Manager, 21 Oct).**
    - Tonight's build (`.github/workflows/tonight.yml`, note 523) now puts `steam_api64.dll` and `libsteam_api.so` into
      `external/steam/` before it packages. They come from the `STEAM_REDIST_URL` secret, as the Release workflow's do, so
      both the win-x64 and linux-x64 dev builds carry them (`DarkTerritory.App` copies `external/steam/` beside the game,
      publish included). The director's Steam friend test (#269, `docs/netcode-audit.md` §4) then needs no DLL copied by hand.
    - **`tools/store/steam_redist.py`** does the fetch. The zip can be Valve's two files alone or the Steamworks SDK's zip
      whole; from the SDK it takes the 64-bit ones (`win64/`, `linux64/`), since the SDK has a 32-bit `libsteam_api.so` too.
      With no secret, a link that fails or a zip with neither file, it does nothing and the build goes on (LAN, direct IP
      and EOS still play). It never fails the build.
    - **The plan says so.** The script adds "A Steam night" to TEST-PLAN.md (in both zips) and to the run's summary. The
      section says whether this build has the library. Without it, the section says what to set and where: Settings >
      Secrets and variables > Actions > New repository secret, `STEAM_REDIST_URL`, a private link to the zip. The section
      also says how to run a Steam friend night:
      - The host starts the game with `--steam` and presses F2 in the night.
      - The friend starts with `--steam` too, and accepts in the overlay or uses Join Game.
      - The fallback is `--join-lobby <id>`.
    - **The host's console prints the lobby's id** once its Steam lobby is open: `Steam lobby <id>: a friend can also join
      with --join-lobby <id>` (`Program.Play`). Nothing showed the id before, so the `--join-lobby` fallback had nothing to
      go on. EOS lobbies show their join code on the status line, as before.
    - **The friend starts with `--steam` too.** The game only starts Steam when asked (`--steam`, an invite's
      `+connect_lobby`, `--join-lobby`, or launched by Steam). A friend's game started plainly has no Steam to hear an
      invite. On app id 480 an invite accepted from the desktop starts Spacewar, not this game; that's #269's to see.
    - **Verified:** `python3 tools/store/steam_redist.py --offline-test`:
      - an SDK-shaped zip gives both libraries, Linux's from `linux64`;
      - a zip of the two files alone works;
      - no secret fetches nothing and the plan says what to set;
      - a broken link skips and says so;
      - a Windows-only zip gives the one file.
      A local `dotnet publish src/DarkTerritory.App` with stand-in files in `external/steam/` put both beside the game.
      The secret itself isn't in this repository: the first night it's set is its real test.
