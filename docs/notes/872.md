   - **The fix.** `Pcg32` (`src/Ballast.Core/Pcg32.cs`) stays a mutable struct; the four fields lose `readonly`, so each
     draw advances the one generator. The sweep found two more copies that repeat draws, both in town generation:
     `TownForms.Clusters` (the fen, borough and salt boardwalks' stage clusters took the walk's generator by value inside
     loops, so the next walk's spacing re-drew the clusters' numbers) and `Homes.Open` (each household's line shuffle forked
     a by-value copy of `houses.spots`, so every household forked from the same state unless an `{other}`/`{absent}` draw
     came between). Both now take it by `ref`. A third, found by the wreck test: `WreckFilm.Ragdoll` took the film's
     generator by value for each player, so every crewmate in a derailment's film got the same kick, spin and side; it
     takes it by `ref` now. `Director.Rng` (a property handing out a copy, unused) is gone. Every other
     by-value `Pcg32` parameter is given a fresh `Streams.Rng(...)`/`rngFor(...)` temporary by its callers, so nothing repeats.
   - **The guard.** `Pcg32CopyTests` (Sim.Tests): reflection over the Sim and Ballast.Core for any `readonly` `Pcg32` field,

     a class was rejected: it would turn every by-value pass (deliberate fresh streams, `Streams.Rng`) into shared state and
     reshuffle every town and line.
