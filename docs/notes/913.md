913. **Playtest telemetry T1: the session recorder and its event schema (n1-H1, nathaniel1; queue #624; the plan, note 907).**
   - Claimed 2026-10-20 19:40 UTC by n1-H1 (nathaniel1), for nathaniel3's plan (note 907).

   - **What it is.** `SessionRecorder` (`src/DarkTerritory.Game/Telemetry/`): each machine records its own session, the host its nights as the host sees them, a client what its player saw and did. It only reads the Sim (the World, the crew's states, the host's incident log `World.Attribution` and encounter log `World.Encounters`, note 880), never writes it, and sends nothing on the wire: nothing in `DarkTerritory.Sim`, no protocol change. `TelemetrySchemaTests.TheNightRunsTheSameWithTheRecorderOrWithout`.
   - **Consent first** (#625's gate, `ITelemetryGate`, n1-N1's shape; note 914). The recorder asks the gate on every line it writes: not `Recording`, nothing's written (switched off mid-night, nothing more); the session line waits for the first line written under consent, so a yes given after the game's up still opens with it (`ConsentIsAskedOnEveryLine`); the session carries the gate's `InstallId`; the file goes in the gate's `SessionsDirectory`, made on the first line, so a session never recorded leaves none. The app's gate is `frontEnd.Playtest` (#625's `PlaytestConsent`, asked on first run, in `telemetry/consent.json`; #1381 landed first, so #1386 made the swap); `--telemetry` records one launch whatever the answer (a `FixedTelemetryGate`, into `--telemetry-dir` or the same folder). `TheWhatWeCollectPageCoversEveryField` pins #625's page (`content/ui/playtest-data.json` `collect`) to the schema: every field but the ones that only say when, and nothing the recorder can't write.
   - **Nothing personal.** A random session id made per session (#625 adds the install id); no names, Steam id, IP, or text anyone typed. The crew is counted (`humans`, `bots`), never named; an incident is its kind and cause, never its line, which names players (`NoNameIsEverWritten`).
   - **Bounded.** The night is looked at once a sim second and rolled up a minute at a time; events only for what happens a few times a night. `dt telemetry record --route frontier:7 --bots 4 --seconds 900`: 43 lines, 8.9 KB for 15 minutes (21 encounters, 3 incidents, 14 minutes); a 45-minute night is well under 100 KB.
   - **Where it goes.** `ITelemetrySink`: `FileTelemetrySink` (one JSON-lines file a session; in the app `%LocalAppData%/DarkTerritory/telemetry/<session>.jsonl`) and `MemoryTelemetrySink` (tests, `dt`). #626 caps and rotates that folder (the spool) and adds the upload.
   - **Headless.** `dt telemetry schema` prints the schema; `dt telemetry record [--route frontier:7] [--bots 4] [--cars 6] [--seconds 600] [--seed 1] [--out out/telemetry]` plays a bot night through the harness (as `dt playthrough --bots`) with the recorder on the host's world and writes its session (#627 builds `dt telemetry summary` on these).

   **The schema** (`TelemetrySchema`; `TelemetrySchemaTests.TheSchemaIsNote913s` reads the list below and holds the code to it, field for field, in order).
   - **Schema version 1.** One JSON object a line. Every line starts `schema` (the version), `type` (below) and `t` (seconds since the session began, the machine's clock; in `dt`, the night's). Then only the type's fields, in this order; a field it can't know is `null` (a client's `net`, a host's `pingMs`). The recorder throws on a type or field not listed, so nothing else can be written. Bump the version when a field's meaning changes or a field or type goes; adding a type or a field at the end is version-compatible for a reader that ignores what it doesn't know, but still changes this list and the test.
   - Every `s` is the night's clock: seconds since the night began (`night`), the yard included, so a player's minutes before the gate count. An incident is timed when it's seen (within the second); an encounter's times are note 880's log's, put on the night's clock. `night` counts the session's nights from 1 (0: between nights); `km` is the train's distance along the line.
     - `session`: `session`, `install`, `build`, `commit`, `edition`, `dev`, `os`, `gpu`, `vr`, `resolution`, `renderScale`, `vsync`, `fov`
     - `night`: `night`, `role`, `route`, `tier`, `cars`, `humans`, `bots`
     - `minute`: `night`, `minute`, `km`, `alive`, `crew`, `frames`, `hitches`, `p50`, `p95`, `p99`, `pingMs`, `loss`
     - `death`: `night`, `s`, `km`, `cause`, `post`, `me`
     - `incident`: `night`, `s`, `kind`, `cause`
     - `encounter`: `night`, `s`, `kind`, `channel`, `where`, `part`, `afoot`, `engagedAt`, `confrontedAt`, `nearAt`, `grabs`, `punishes`, `end`, `endedAt`
     - `first`: `night`, `what`, `s`
     - `purchase`: `what`, `cost`, `scripAfter`
     - `rebind`: `control`
     - `menu`: `name`, `seconds`
     - `prompt`: `night`, `name`, `acted`
     - `nightEnd`: `night`, `end`, `seconds`, `km`, `carsDelivered`, `carsLost`, `cargoDelivered`, `net`, `crewHome`, `crewLost`, `deaths`, `encounters`, `hitches`, `p50`, `p95`, `p99`
     - `quit`: `how`, `night`, `s`

   - **The field groups** (for #625's "what we collect" page, `content/ui/playtest-data.json` `collect`, which must cover each; n1-N1 pins that with a test):
     - **The session and the machine:** `session.session`, `install`, `build`, `commit`, `edition`, `dev`, `os`, `gpu`, `vr`, `resolution`, `renderScale`, `vsync`, `fov`.
     - **The night's setup:** `night.role`, `route`, `tier`, `cars`, `humans`, `bots` (counts, never names).
     - **How the night went:** `minute.km`, `alive`, `crew`; `nightEnd.end`, `seconds`, `km`, `carsDelivered`, `carsLost`, `cargoDelivered`, `net`, `crewHome`, `crewLost`, `deaths`, `encounters`.
     - **Deaths:** `death.s`, `km`, `cause`, `post`, `me`.
     - **What happened** (the host's logs, kinds only): `incident.kind`, `cause`; `encounter.kind`, `channel`, `where`, `part`, `afoot`, `engagedAt`, `confrontedAt`, `nearAt`, `grabs`, `punishes`, `end`, `endedAt`.
     - **Learning the game** (UX friction): `first.what`, `s`; `prompt.name`, `acted`; `menu.name`, `seconds`; `rebind.control`.
     - **The fortress** (economy): `purchase.what`, `cost`, `scripAfter`.
     - **How it ran** (performance and the link): `minute.frames`, `hitches`, `p50`, `p95`, `p99`, `pingMs`, `loss`; `nightEnd.hitches`, `p50`, `p95`, `p99`.
     - **Leaving:** `quit.how`, `night`, `s`.
     - Every line's `schema`, `type`, `t`, and `night`/`s`/`minute`, which say when.
   - The fields: `session`: `install` the gate's random install id (#625), the build (`Report.Build()`: version and commit), `edition` (`full`/`demo`), `dev` (a dev build), `os`, `gpu` (the device's name), `vr`, and the display settings. `night`: `role` `host`/`client`/`solo`, the route's name and tier, cars (not the engine). `minute`: the frames shown that minute and their 50th/95th/99th percentile ms (1 ms bins), hitches (FrameWatch's: at least 25 ms and twice the last minute's median), a client's ping (ms) and snapshot loss (0–1). `death`: `cause` a `DeathCause`, `post` where they were working (`Census.PostOf`: Cab, Gunner, Walker, Rider, Ground, LeftBehind), `me` this machine's player. `incident`: an `IncidentKind` and, for a death, its cause. `encounter`: note 880's record (kind, channel Pressure/Free/Fill/Stop/Special/World, where, the train's third, afoot; `engagedAt`, `confrontedAt`, `nearAt`, `endedAt` seconds or null for never; grabs, punishes; `end` About/Killed/Gone). `first`: `move` (this machine's player a metre from where they began, or onto another car), `job` (driving, firing or seated at a gun), `stop` (the train at a stand once it's 200 m out), `delivery`. `purchase`, `rebind`, `menu`, `prompt`: from the app's front end (the recorder's calls; T1 wires the night's, below). `nightEnd`: the run's report (`RunReport`; null for a client, which has none) and the night's frames. `quit`: `how` `menu` (left mid-night), `app`, `kicked`, `disconnected`.

   - **In the app** (`DarkTerritory.App/Program.cs`): the recorder's made at start-up (`SessionRecorder.ToFile`, `--telemetry-dir` to put it elsewhere), `session` written once the GPU's known; `Play` begins the night on the host's world where there is one (`net.Host.World`, which has the incident and encounter logs), else the session's; after each sim tick, once a sim second, the link (`LinkInfo.PingMs`, `Loss`) and the crew (`IPlaySession.CrewStates`); each frame its `dt`; the night's end (left before its end: `quit` first, `kicked`/`disconnected`/`app`/`menu`); the app's `quit` once.
