   - **The Creature Tweaker** (claude.ai/artifact/TdoxfYnmZTgv2jc9JmRkkw; source `tools/tweaker/creature-tweaker.html`). A card per creature, the 23 the director spends on: how often (×), cost, most in a night, nights it comes at all (%), the tier weights where it has them, "Leaves at dawn", and a note to the agents; the night-wide seconds before dawn. Each card shows what's in the game beside each value and goes amber while the director's values differ from it (or a note waits for an answer).
